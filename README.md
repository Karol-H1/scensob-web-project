# SCENSOB Web Project

Design and build of the SCENSOB Global site plus two divisional sites (IT, Transport & Delivery), unified under one shared design system. Internship project — team: Karol Harasim, Daniel Boateng. Mentor: Daniel Dankwa.

## Structure

- **`design-system/`** — the shared SCENSOB logo (`scensob-logo.svg`) and a browser preview of it on light/dark backgrounds.
- **`wireframes/`** — HTML mockups per site, one folder each:
  - `global/` — SCENSOB Global hub (Home only so far).
  - `it/` — IT division (Home only; content is placeholder pending real services from the IT HOD).
  - `transport-delivery/` — Transport & Delivery, the most complete: Home, Services, About, Catalog, and Contact, all built with real content ported from the team's Figma draft.
- **`content/`** — content inventory, copy, and SEO notes (to be filled in as Discovery/content confirmation completes).

## Status

- Design system (color, type, logo): established, applied consistently across all three sites.
- Wireframes: Transport & Delivery has all 5 core MVP pages with real content. Global and IT have Home only; IT is blocked on confirmed service content from the IT HOD.
- Photography: still placeholder everywhere — stock photos to be sourced and swapped in next.
- Build: nothing built in the CMS yet — these are HTML reference mockups, not the final WordPress site.

## Stack

WordPress (free/self-hosted) + Elementor, Contact Form 7, Yoast SEO — all free-tier, per the project's no-budget constraint.
